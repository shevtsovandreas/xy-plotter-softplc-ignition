# Hardware

This directory contains hardware documentation for the updated XY Plotter automation architecture.

## Raspberry Pi 5

The Raspberry Pi 5 replaces the original Siemens PLC and HMI platform, hosting CODESYS SoftPLC, Ignition Gateway, and PostgreSQL.

## Other Hardware Components

The remaining hardware components, including the ESP32 motion controller, W5500 Ethernet module, stepper motors, drivers, sensors, and mechanical assembly, **remain unchanged from the original project**.

For hardware specifications, wiring diagrams, and electrical documentation, refer to the previous repository:

**[XY Plotter Automation — Original Project](https://github.com/shevtsovandreas/xy-plotter-automation)**

This repository focuses on the updated control and software architecture rather than duplicating the original hardware documentation.
